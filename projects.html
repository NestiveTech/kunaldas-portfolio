LibNest

Jan 2025 – Present

Role: Team Leader, Backend & Database Programmer

Technologies: Python, PyWebView, MySQL


Definition: LibNest is a next-generation Library Management System designed to streamline library operations efficiently. It offers features such as student tracking, fee reminders, seat management, revenue monitoring, and real-time scheduling. The platform enhances user experience by automating administrative tasks, providing advanced analytics, and ensuring secure access controls.



✔️Engineered a complete Library Management System using Python 3.8+ with PyWebView 3.6 framework, implementing 50+ modules including Book_issue_register_API.py, Submit_API.py, and Renewbook_API.py for core circulation workflows with MySQL 8.0 backend (654545_library_db schema).


✔️Designed and optimized a 7-table relational database schema with proper normalization (3NF), including books (ISBN, title, author, edition), book_stock (inventory tracking), students (demographic data), borrowed_books (transaction records), and cash_book (financial transactions).


✔️Implemented secure authentication system using bcrypt password hashing with salt rounds=12, coupled with role-based access control (3 levels: super-admin, librarians, students) through the login.py and user_authentication.py modules.


✔️Developed comprehensive library workflows including: automated book issuing with validation checks (valid_Students(), valid_Books()), return processing with fine calculation (₹10/day late fee), renewal system (15-day extensions), and clearance certificates (Library_clearence.py).


✔️Built a hybrid desktop application architecture using PyWebView to render responsive HTML5/CSS3/ES6 frontend (20+ UI screens) within native windows, achieving 95% cross-platform compatibility (Windows/Linux/macOS).


✔️Created specialized modules for: Excel bulk uploads (UPLOAD_DATA.py handles .xlsx processing), PDF generation (ReportLab for certificates and reports), and automated email reminders (REMINDER_EMAIL.py with configurable SMTP settings).


✔️Implemented real-time search functionality across all modules with client-side JavaScript filtering and server-side MySQL LIKE queries, supporting search by ISBN, title, author, or student ID.


✔️Designed a comprehensive dashboard system (dashboard.py) with: live counters for issued books, pending returns, and payments; quick-action buttons; and institution-specific data filtering for multi-college support.


✔️Developed robust error handling with: database connection pooling, transaction rollbacks on failures, input validation (validation.py for emails, phone numbers), and automated backups (daily incremental + weekly full).


✔️Conducted thorough testing including: 85+ unit tests (PyTest), integration testing of complete workflows (issue-renew-return-fine cycle), and stress testing with 100+ concurrent simulated users.


✔️Documented the system with: API specifications (RESTful endpoints), database schema diagrams, deployment guide (including Python package dependencies), and user manuals for librarians and administrators.


✔️Deployed at Falakata Polytechnic with measurable outcomes: 70% reduction in manual processes, 60% faster book search/checkout times, and support for 500+ active users across multiple departments.

Smart Accident Prevention, Detection, and Reporting System (SAPDRS)

Jul 2024 – Dec 2024

Role: Team Leader, Circuit Designer, Embedded Programmer

Team Members: Kunal Das, Arindam Das, Nirmal Barman, Chanchal Mandal, Bivash Das, Shilajit Paul, Raj Barman

Guide: Mr. Lakhan Deo Oraon, Lecturer, Department of ETCE, Falakata Polytechnic

Institution: Falakata Polytechnic, West Bengal State Council of Technical & Vocational Education and Skill Development

Technologies Used: ESP32 microcontroller, GPS Module (NEO-6M), GSM Module (SIM900A), MQ3 Alcohol Sensor, Ultrasonic Sensor, MPU6050 Accelerometer, PIR Sensor, OLED Display, TP4056 Battery Charger, L293D Motor Driver, Voltage Regulators, Arduino IDE


    ✔️Designed and developed a real-time embedded system to prevent, detect, and report road accidents using IoT sensors and wireless communication.


    ✔️Integrated ESP32 microcontroller with a GSM module to transmit emergency SMS alerts containing GPS coordinates during detected accidents.


    ✔️Implemented an alcohol detection system using the MQ3 sensor to monitor the driver’s condition before driving.


    ✔️Used ultrasonic sensors for proximity detection to reduce collision chances by alerting the driver in real-time.


    ✔️MPU6050 accelerometer and vibration sensors detect abrupt motion or impacts to confirm an accident scenario.


    ✔️PIR sensor helps determine driver movement or consciousness post-accident for intelligent response triggering.


    ✔️Deployed a 1.3" OLED display for onboard system status and alert visualization.


    ✔️Powered the system with lithium-ion batteries and step-down regulators, featuring overvoltage and discharge protection via TP4056 modules.


    ✔️Created a user-friendly Android application using MIT App Inventor for system control and alert monitoring.


    ✔️System auto-locks the vehicle post-accident using motor drivers to prevent further harm.


    ✔️Inspired by a real-life accident experience, this solution addresses the gap in emergency responsiveness by providing automated and accurate location-based incident reporting.


    ✔️Improved emergency response time by up to 30%, potentially saving lives by reducing critical delays.


    ✔️Tested successfully in lab and semi-outdoor environments for reliability, sensor accuracy, and communication stability.
